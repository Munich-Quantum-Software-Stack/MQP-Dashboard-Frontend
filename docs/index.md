# MQP Dashboard Frontend Documentation

Welcome to the MQP Dashboard Frontend documentation.

This site provides project-level guidance for setup, development, and
maintenance.

## Scope

The MQP Dashboard Frontend is the React-based user interface for MQSS
platform workflows.
It provides views and interactions for user authentication, resources,
jobs, budgets, and tokens.
